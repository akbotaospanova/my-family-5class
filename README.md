# My Family Galaxy — Grade 5 · Lesson 25

Interactive English lesson site: **Unit 3 Values · Vocabulary: The family** (Excel 5).

## Contents
- Word cards with audio (14 family words, Kazakh / Russian translation)
- Grammar box: possessive 's, *whose*, *who's*
- Interactive family tree
- Task 1 (A) Word Match · Task 2 (B) Who is who? · Task 3 (C) Who's or Whose? + pair talk
- Games: What's missing?, Memory Match, Speed Quiz
- Intellectual zone: family riddles
- Videos, reflection ("Tree of Success", 10-point scale), differentiated homework
- Values link: **Adal Azamat**

## How to publish on GitHub Pages
1. Create a new public repository and upload `index.html` and `README.md`.
2. Open **Settings → Pages**.
3. Under **Source** choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. After 1–2 minutes the site opens at `https://<your-username>.github.io/<repository-name>/`.
